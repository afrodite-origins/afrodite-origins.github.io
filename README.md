# Afrodite Alpha — A Ascensão e o Triunfo de Afrodite

Protótipo de RPG tático por turnos no navegador, inspirado em souls-like: Afrodite enfrenta Hefesto, o deus da forja, em duas fases.

**Jogar:** abra `index.html` no navegador (ou acesse a página do GitHub Pages deste repositório).

## Controles
- **Mouse:** clique nas casas para andar, clique no botão de ações ou use o menu radial.
- **Teclado:** setas traçam o caminho, Espaço confirma, Q abre o menu, Enter passa o turno, F apara, Shift + seta desvia, P liga a luta automática.
- **Controle:** analógico/direcional traça o caminho, X confirma e apara, A pula, B + analógico desvia, Y passa o turno, LB abre o menu.

## Celular
- Jogue com o celular **na horizontal** (o botão *Tela cheia* ajuda).
- Toque uma vez para ver (caminho, mira, ação do menu) e toque de novo no mesmo lugar para confirmar.
- No turno de Hefesto: botões **Aparar** e **Pular** na tela; toque numa casa vizinha para desviar.
