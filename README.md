# Afrodite Alpha

Protótipo de RPG tático por turnos, de tom sombrio: Afrodite enfrenta Hefesto, o deus da forja.

**[Jogar](https://isaacbcampos.github.io/afrodite-alpha/)** · funciona no PC e no celular (na horizontal).

## Últimas atualizações

**Alpha 0.11 (experimental) · 26/11/2026**

- Desempenho: o fundo, o tabuleiro, a vinheta e os retratos agora são desenhados uma vez e reaproveitados, e a câmera de reação ficou bem mais leve.
- Movimentos mais lisos, que acompanham a taxa de quadros real do aparelho.
- Indicador de FPS no canto superior esquerdo (dá para esconder na engrenagem).

**Alpha 0.10.9 (experimental) · 26/11/2026**

- Mais dados de comportamento para o desenvolvedor: tempo de decisão, precisão das notas e das reações, uso dos menus, trocas de aba, tela cheia e desempenho.

**Alpha 0.10.8 (experimental) · 26/11/2026**

- Coleta de dados mais confiável, principalmente no celular: o jogo envia os dados logo no começo e a cada troca de tela, e não perde mais as lutas quando o servidor recusa um campo.

**Alpha 0.10.7 (experimental) · 26/11/2026**

- Tela de escolha do caminho mais limpa: só as 4 classes, a Personalizada e um ícone para reportar bug.
- Se o jogo travar, aparece uma tela para destravar e continuar, voltar ao início do turno ou recomeçar a luta. O travamento é relatado automaticamente.
- Se você fechar ou recarregar a página no meio da luta, a primeira tela oferece continuar de onde parou.
- Na engrenagem há a opção "O jogo travou? Destravar".
- A câmera de reação agora está sempre ligada.

[Ver todas as atualizações](CHANGELOG.md) · [Jogar a versão estável (0.9.9)](https://isaacbcampos.github.io/afrodite-alpha/estavel/) · achou um bug? Use o botão **Reportar bug** dentro do jogo.

## Controles
| | PC | Controle |
|---|---|---|
| Andar | clique / setas + Espaço | analógico + X |
| Ações | Q | LB |
| Passar turno | Enter | Y |
| Aparar | F | X |
| Pular | Espaço | A |
| Desviar | Shift + direção | B + direção |

No celular: um toque mostra, o segundo confirma.

## Créditos
Trilha: "Forging Flames", de Patrick Maney ([OpenGameArt](https://opengameart.org/content/forging-flames-cinematic-dark), CC-BY 3.0).

O jogo registra dados anônimos de partida (tempo, mortes, habilidades usadas) para ajudar nos testes.
